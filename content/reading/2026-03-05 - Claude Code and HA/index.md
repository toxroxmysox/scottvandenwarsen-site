The linked article is Jen's experience using Claude Code to level-up smart home automation and dashboards for a connected home, and while I'm excited to try that use case in the future, I've started using Claude Code myself for this very website!

Claude Code has been in the tech news a ton in recent months and I know I'm not alone in the group of people exploring the AI tool for the first time. I first started this website talking to ChatGPT to develop the system for how to write, publish, host, and maintain my personal website, but now I eliminate all the copy/paste and back and forth between the system, me, and the LLM, and instead Claude Code can directly help manage the site. 

It's removed all the barriers from "I have an idea" to making that idea come to life, and I know it'll keep getting better and better.
